# Nimbus Serpent — coolest-art-01

A storm cloud coiled like a serpent around one huge glowing cyan eye, staring down at a tiny red-sailed boat on a dark sea, with lightning striking toward the water.

`main.py` (Python 3.13, standard library only) draws the picture with a small software renderer — sky, sea, rain, eye glow, coil, eye, lightning, boat — and writes `entry.png` (1024x1024 PNG) to `$MAKEFUN_OUTPUT_DIR` (or `/output` when unset). Deterministic: the same bytes on every run.
